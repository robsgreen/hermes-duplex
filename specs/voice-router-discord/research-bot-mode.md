# Research: Hermes Bot Mode (2026-11-04)
- Bot Mode = Hermes Desktop UI over profiles ("A Bot is a Hermes profile"): one permanent "Bot Chat" per profile, roster/avatars, routines (cron), group chats of 2–6 bots, bot-to-bot DMs via message_agent, cross-machine via `hermes peer` (posts to peer /v1/runs with the Bot Chat session id). Shipped ~v0.21 (Aug 2026), changing weekly (many open PRs/issues).
- Not Discord/voice: no per-profile Discord voice bot; no people/permissions; one chat per profile (not per person); switching is a Desktop click/@mention with no API. Titles live in profile.yaml ui_meta (not exposed by API server).
- message_agent only in sessions titled "Bot Chat" on a Bot-Mode-managed install → cannot leak into our runs.
- Evaluation: no overlap/replacement; using it would add complexity (N Discord bots) or break per-person context (shared Bot Chat). Supports the amendment's direction. Recommendations: confirm amendment; copy name-resolution order (exact name → aliases/titles → refuse ambiguous with list); aliases may mirror Bot titles manually; docs: "profile" = Desktop "Bot", voice sessions are not Bot Chats, use a separate Discord token from any profile gateway bot; revisit if message_agent lands in gateway sessions (#131849, #101057) or titles get exposed.
