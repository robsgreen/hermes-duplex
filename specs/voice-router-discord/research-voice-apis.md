- GPT-Live (gpt-live-1, GA 2026-09-10, $0.05/min): separate product from Realtime; /v1/live/sessions, client.live.connect() (openai 3.42.1). OpenAI: "for a new conversational voice app, start with GPT-Live". No own tools; session.delegation.type = client (default) | responses | decisions.
  - Client delegation: session.delegation.created {delegation.id, target, offset_ms} -- metadata only, NOT task text; app derives task from session.input/output_transcript.delta. Return via session.commentary.append (spoken, paraphrased), session.thinking.append (silent ctx), session.instructions.append; <=500 tokens each, many per delegation_id.
  - session.triggers (DecisionTrigger on input/output_transcript.delta) fire Decisions independently; decisions delegation -> decision.event/decision.completed.
  - Concurrency 50/300/500 by tier. Session max duration undocumented.
- OpenAI Realtime GA (gpt-realtime-2.1, 128k ctx, audio $32/$64 per 1M): WebSocket for server bots; pcm 24k mono; server_vad/semantic_vad, create_response/interrupt_response; client must stop playback + conversation.item.truncate(audio_end_ms) on speech_started; function_call -> conversation.item.create function_call_output + response.create; no documented async-tool flag; 60-min session cap.
- xAI Grok Voice (grok-voice-latest=3.0, wss://api.x.ai/v1/realtime): near drop-in for OpenAI Realtime via OpenAI SDK base_url; flat session shape; server_vad only; truncate may be unimplemented; force_message, resumption via conversation_id; client function tools + server tools (web_search, x_search, mcp); $0.08/min. No delegation mode.
- Gemini Live (gemini-3.8-live, GA 2026-09-15): own BidiGenerateContent WS, 16k in/24k out; NON_BLOCKING tools w/ scheduling INTERRUPT/WHEN_IDLE/SILENT (closest to GPT-Live); 15-min audio session w/o compression, ~10-min connections, resumption tokens.
