- `RealtimeProvider.say(text, *, expects_answer: bool = False)`. - `update_instructions(text)` raises (any Exception) when the server rejects the update or no `session.updated` arrives within a timeout; the session's existing except → restart path then applies. A rejection must not be counted as a refused response by the floor.
